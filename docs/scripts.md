# 脚本

## format

用于格式化项目与插件代码, 使用 prettier 作为格式化工具.

示例:

```bash
pnpm format
```

## build-plugin

编译 plugins 目录下的 ts 插件.

示例:

```bash
pnpm build-plugin
```

## clean-plugin

清理 plugins 目录下 ts 插件的编译结果.

示例:

```bash
pnpm clean-plugin
```

## start

编译 plugins 目录下的 ts 插件并运行 bot.

示例:

```bash
pnpm start
```
